# Front End Development Frameworks for Web Applications — Lab Experiments

This repository contains front-end lab experiments built with HTML, CSS, and JavaScript.

## Experiments

| Lab | Experiment | Main concepts |
| --- | --- | --- |
| LAB-4 | E-commerce Website Homepage | CSS Flexbox, CSS Grid, animations, responsive design, JavaScript interactions |
| LAB-5 | Responsive Student Admission Form | CSS Grid, media queries, form validation, responsive layout |
| LAB-6 | Student Result Management System | DOM manipulation, marks calculation, grade calculation, browser storage, CSV export |
| LAB-7 | Weather Information Dashboard | Modern JavaScript, async/await, Fetch API, external weather API, error handling |

## How to run

1. Download or clone this repository.
2. Open the required lab folder in Visual Studio Code.
3. Open the `.html` file in a browser, or use the Live Server extension in VS Code.
4. For LAB-7, an internet connection is required to fetch weather data from the API.

## Notes

- Each experiment is provided as a standalone HTML file containing its HTML, CSS, and JavaScript.
- LAB-6 stores demo records in the browser; it does not connect to a central database.
- LAB-7 depends on the configured weather API and network availability.
